INSTRUCOES PARA CARREGAR INFORMACOES NO POSTGRESQL DOCKER
=========================================================

Execute os comandos no PowerShell, a partir da pasta do projeto:

    cd "C:\Faculdade\SI\Resort-Paraiso-Atlantico"

1. Confira se o container esta em execucao:

    docker ps

O nome esperado do container e postgres-resort. Se o nome for diferente,
substitua postgres-resort nos comandos abaixo pelo nome exibido em CONTAINER ID
ou NAMES. As tabelas ja devem existir no banco resort antes de executar os
proximos comandos.

2. Opcionalmente, carregue os dados iniciais do projeto:

    Get-Content dados.sql | docker exec -i postgres-resort psql -U postgres -d resort

3. Carregue a massa de teste:

    Get-Content carga_teste.sql | docker exec -i postgres-resort psql -U postgres -d resort

Se o container ainda nao existir, crie-o com:

    docker run --name postgres-resort -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=resort -p 5555:5432 -d postgres

Depois, carregue os arquivos seguindo a ordem indicada acima.

* ATENCAO: o comando abaixo apaga todas as tabelas e os dados do banco resort.
    Use somente se quiser limpar o banco antes de inserir as informacoes novamente:

        docker exec -i postgres-resort psql -U postgres -d resort -c "DROP SCHEMA public CASCADE; CREATE SCHEMA public;"
